📘 Student Info Analyzer & Performance Tracker (Python)
📌 Project Overview

This project is a Python CLI-based application designed to practice and demonstrate the use of core Python data structures such as lists, tuples, dictionaries, and sets.
It collects student details, processes academic data, and displays meaningful analysis.

The project is built in progressive levels, starting from basic input handling to a menu-driven student performance tracker.

🎯 Objectives

Take user input and store data efficiently

Apply Python data structures correctly

Perform basic data processing and analytics

Build confidence with CLI-based programs

🧠 Concepts Used

Strings & String Formatting

Lists

Tuples

Dictionaries

Sets

Loops & Conditionals

Functions (for advanced version)

Menu-driven CLI programs

🧩 Features
✅ Basic Student Info Analyzer

Takes name and age

Stores favorite subjects in a list

Stores roll number and branch in a tuple

Stores subject-wise marks in a dictionary

Stores technical skills in a set

Displays all collected information

✅ Enhanced Analyzer (Comma-Separated Input)

Formats full name in title case

Sorts favorite subjects alphabetically

Calculates:

Total Marks

Average Marks

Highest Scoring Subject

Removes duplicate skills automatically

✅ CLI-Based Student Performance Tracker

Menu-driven interface:

Add Student

View All Students

Analytics

Exit

Stores multiple students

Ranks students by total marks

Finds subject-wise toppers

Displays most common technical skills
