🐍 Python Winter Sprint 2026 – Vault OS
A learning-focused Python sprint organized around real-world mini projects to master:
Lists, Tuples, Dictionaries, Sets
File Handling (JSON)
CLI Menus & Loops
Data Persistence
Basic Project Architecture
This sprint is designed for beginners → intermediate learners and is divided into three tracks.
📚 Tracks Overview
🟢 Foundation Track (Beginners)
Core Topic:
Lists
Tuples
Dictionaries
Sets
🧠 Problem Statement:
Build a Python program that:
Takes input:
Username
Platform name (GitHub, Gmail, etc.)
Account type (Personal / Work)
Stores:
All usernames → List
(Platform, Account Type) → Tuple
Username → Platform → Dictionary
Unique account types → Set
🔵 Core Track (Vault Lite – File Based Credential Manager)
Core Topic: File I/O (JSON)
🎯 Objective:
Build a CLI app that can:
Save credentials
Read credentials
Update credentials
Store data in a file (vault_data.json)
Keep data even after program restarts
✅ Features:
Main Menu (Loop based)
View credentials
Add credential
Update credential
Exit
Each credential contains:
Website
Username
Password
Data stored in:
Copy code

vault_data.json
❌ Not Required:
No delete option
No encryption
No animations
No complex error handling
